# Senior Trip Planner

Senior Trip Planner is a beginner-friendly travel planning app for senior travelers.

It helps create calm, comfortable, senior-friendly travel itineraries with:

- relaxed daily pacing
- rest breaks
- walking-distance preferences
- hotel / apartment preferences
- food preferences
- guided-tour preferences
- map planning
- live weather checks
- multilingual UI support
